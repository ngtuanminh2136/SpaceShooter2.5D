# SpaceShooter 2.5D

Một tựa game bắn súng vũ trụ góc nhìn từ trên xuống, được phát triển bằng Python và Pygame.

## 🎮 Tải Game (Dành cho người chơi)

Bạn không cần cài đặt Python để chơi. Chỉ cần tải bản đóng gói sẵn:

👉 **[TẢI GAME TẠI ĐÂY](https://github.com/ngtuanminh2136/SpaceShooter2.5D/releases/latest)**

**Cách chơi:** Tải file `SpaceShooter25D.rar` về máy -> Giải nén -> Mở file `SpaceShooter25D.exe` để chơi.

## ⌨️ Điều khiển

* **W, A, S, D / Mũi tên:** Di chuyển phi thuyền
* **Chuột trái:** Bắn súng
* **ESC / SPACE:** Tạm dừng game
* **N:** Chơi màn tiếp theo (khi thắng)
* **R:** Chơi lại màn
* **M:** Về Menu chính
